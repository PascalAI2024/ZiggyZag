# ZiggyZag `v0.1.0-alpha.3`

*The Wave 2 polish release — themes, brand, docs, ops, five bug fixes.*

## What you can do with this release that you couldn't with `alpha.2`

**One theme selection drives shell prompt accent AND terminal palette.** Set `ZIGGYZAG_THEME=tokyo-night` in any terminal, or cycle with `Ctrl+Shift+T` inside the desktop host, and both surfaces move together. A new `theme` shell builtin (`theme`, `theme list`, `theme <id>`, `theme --json`) makes the active theme inspectable and switchable from the command line. Spec: [`docs/reference/theme-protocol.md`](../reference/theme-protocol.md).

**Twenty themes ship.** The registry grew from 13 to 20: added `catppuccin-frappe`, `catppuccin-macchiato`, `catppuccin-latte`, `tokyo-night-storm`, `solarized-light`, `github-light`, `ayu-dark`. Every theme has been audited against WCAG 2.1 AA contrast (fg/bg, accent/bg, muted/bg, ANSI-red/bg). Audit report: [`docs/reference/accessibility.md`](../reference/accessibility.md). Audit script: `scripts/audit_contrast.py` (re-runnable on demand, exits non-zero on AA failure).

**A landing page.** [`docs/index.html`](../index.html) is GitHub Pages-ready. Hero animation, theme gallery, install one-liner, wave timeline, AgentD architecture preview.

**An honest review of the project as it stood at the start of this wave.** [`docs/reviews/2026-05-17-baseline.md`](../reviews/2026-05-17-baseline.md) is the external audit that anchored the masterplan. [`docs/reviews/2026-05-17-polish.md`](../reviews/2026-05-17-polish.md) is the four-round polish-pass log including agent-finding true-positive rate (42%).

## Bug fixes

Five real defects, all with regression tests:

1. **AgentD watchdog deadlock.** Every `rg.search` and `git.diff` call blocked for the full 30-second timeout and returned `error.ToolTimedOut`, because the watchdog's `std.Io.sleep` was uncancellable and `fired` was set unconditionally. Fixed in `apps/agentd/src/tools.zig` via a 100 ms polling loop with a `main_done` atomic flag.
2. **`theme` directive silently ignored in `~/.ziggyzagrc`.** Added to dispatcher and `isConfigDirective`.
3. **JSON encoder produced invalid output for sub-0x20 control bytes.** The shell's `appendJsonString` only escaped `\n`, `\r`, `\t`; now matches RFC 8259 with `\u00XX` for every remaining sub-0x20 byte.
4. **History metadata never loaded on startup.** `ZIGGYZAG_HISTORY_DB` was written at exit but never read at start; `history --stats` couldn't see prior sessions. Added `readHistoryMetaFile` paired with the existing write path.
5. **`dir_index` mutated before `chdir` succeeded.** `back`/`forward`/`jump` set the index before calling `setCurrentPath`; on failure, state was left wrong. Now updates only on success.

Plus seven candidate findings ruled NOT REAL on careful re-verification — documented in the polish review so future audits don't re-report them.

## Honest status

- **Windows desktop**: alpha. At this tag the ConPTY I/O bridge was structurally broken — the host spawned but typed commands never executed. Four bugs were root-caused and fixed in post-tag commits (2026-05-17); with those applied the host is genuinely drivable. Full provenance: [`docs/reviews/2026-05-17-windows-debug.md`](../reviews/2026-05-17-windows-debug.md).
- **macOS / Linux desktop**: launcher only. Native graphical hosts arrive in Wave 3.
- **Shell**: alpha-ready cross-platform.
- **AgentD**: alpha, local-only by default, falls back gracefully when no provider configured.

The full alpha-readiness picture: [`docs/vision/alpha-tasks.md`](../vision/alpha-tasks.md). The wave plan: [`docs/vision/waves.md`](../vision/waves.md).

## Download verification

Every release zip is paired with `checksums.sha256` in the release assets. Verify before extracting:

```sh
sha256sum -c checksums.sha256 --ignore-missing
```

```powershell
Get-FileHash -Algorithm SHA256 .\ZiggyZag-v0.1.0-alpha.3-windows-x86_64.zip
# Compare to the hash in checksums.sha256.
```

The `install.sh` / `install.ps1` scripts do this automatically.
