A shell, a terminal, and an agent — in one weekend's worth of Zig.

ZiggyZag is a readable shell, a native Windows terminal host, and a local AI sidecar that share themes, events, and approval semantics. No accounts. No JavaScript. No nonsense.

What's in the box

Three small binaries that act like one product. Each one is readable in a focused sitting.

$

Readable shell

REPL, parser, builtins, completion, history, jobs, prompt themes. Roughly 5,600 lines of Zig you can step through.

▣

Native terminal host

Windows-native Win32 + ConPTY host with split panes, search, palette, themes, mouse-wheel scrollback, alternate screen.

◆

Local AI sidecar

AgentD speaks JSON-lines over stdio. Approval-aware for any mutation. Sandboxed file reads with realpath containment.

◴

Unified themes

One theme selection drives shell prompt accent AND terminal palette via the ZIGGYZAG_THEME env var. 20 themes, one keystroke to cycle, WCAG-audited.

→

Shell integration

OSC 777 events for prompt, cwd, status, duration, jobs, project kind, git state. No screen scraping required.

✓

An agent that asks before it acts

AgentD is a small JSON-lines process. Every tool declares its approval policy as data: none for read-only, ask for terminal/build writes, host for actions the desktop performs on AgentD's behalf. The desktop panel previews the exact bytes before any approval.

⤓

Bounded reads

64 KB per file.read, 96 KB per command stdout, 24 KB per stderr. Output gets redacted for tokens, keys, and secret patterns.

⛨

Sandboxed paths

Three layers: lexical filter, final-component lstat, realpath containment. Sibling-prefix and symlink escapes covered by tests.

↻

Local providers

Ollama and OpenAI-compatible endpoints. No telemetry to Anthropic, OpenAI, or anyone else by default.

Why this exists

Most shells are mature production tools carrying decades of compatibility code. Most terminals are walls of C or large Rust projects with their own ecosystems. There is a middle band — small enough to read in a focused sitting, complete enough to demonstrate the hard parts, written in a language where memory ownership, process spawning, and terminal behavior stay visible.

ZiggyZag is that band. It started as a finished CodeCrafters "Build Your Own Shell" project, kept growing because every feature taught a shell concept, and is now an open-source learning lab that aims for daily-driver respectability.

If you are learning Zig, learning how shells work, or just want a terminal you can fully inspect — start at Quick Start and end at Masterplan.
